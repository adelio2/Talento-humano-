# Historias de Usuario

| Código | Historia de Usuario |
|---------|---------------------|
| HU-01 | Como usuario del sistema, quiero iniciar sesión con usuario y contraseña para acceder únicamente a las funciones permitidas según mi rol. |
| HU-02 | Como usuario, quiero recuperar mi contraseña mediante correo electrónico para volver a ingresar al sistema en caso de olvido. |
| HU-03 | Como empleado, quiero crear solicitudes de permisos laborales para gestionar ausencias autorizadas. |
| HU-04 | Como empleado, quiero solicitar vacaciones indicando fechas y motivo para gestionar mi descanso laboral. |
| HU-05 | Como empleado, quiero solicitar certificados laborales para obtener documentos oficiales emitidos por Talento Humano. |
| HU-06 | Como empleado, quiero registrar incapacidades médicas adjuntando soporte clínico para justificar mi ausencia laboral. |
| HU-07 | Como jefe inmediato o usuario autorizado de Talento Humano, quiero aprobar solicitudes para autorizar su ejecución. |
| HU-08 | Como jefe inmediato o usuario autorizado de Talento Humano, quiero rechazar solicitudes indicando el motivo para informar al empleado. |
| HU-09 | Como sistema, quiero asignar automáticamente un responsable inicial según el tipo de solicitud para iniciar el flujo de revisión. |
| HU-10 | Como usuario de Talento Humano, quiero recibir alertas automáticas cuando una solicitud permanezca más de 3 días sin movimiento, para evitar retrasos. |
| HU-11 | Como usuario de Talento Humano, quiero que el sistema valide el saldo disponible de vacaciones antes de aprobar solicitudes, para evitar inconsistencias. |
| HU-12 | Como usuario de Talento Humano, quiero que el sistema genere automáticamente certificados laborales aprobados, para reducir procesos manuales. |
| HU-13 | Como usuario de Talento Humano, quiero buscar solicitudes mediante un número de radicado, para encontrarlas rápidamente. |
| HU-14 | Como empleado, quiero adjuntar documentos de soporte en solicitudes de permisos e incapacidades, para justificar correctamente mi solicitud. |
| HU-15 | Como usuario de Talento Humano o Gerencia, quiero consultar el historial de cambios de las solicitudes, para auditar acciones realizadas. |
| HU-16 | Como empleado, quiero editar mi solicitud mientras esté en estado pendiente, para corregir información antes de ser procesada. |
| HU-17 | Como usuario, quiero recibir notificaciones por correo electrónico además de las internas del sistema, para mantenerme informado sobre el estado de mis solicitudes. |
| HU-18 | Como usuario de Talento Humano, quiero consultar reportes de tiempos de respuesta por tipo de solicitud y responsable, para evaluar el desempeño del proceso. |
| HU-19 | Como usuario de Talento Humano, quiero cambiar una solicitud al estado "En revisión" cuando necesite validaciones adicionales, registrando obligatoriamente una nota explicativa. |
| HU-20 | Como responsable de Talento Humano, quiero consultar las solicitudes anteriores de cada empleado mediante filtros por estado, tipo de solicitud, fecha y empleado, para revisar la información registrada de forma más organizada y eficiente. |
| HU-21 | Como empleado, quiero consultar el historial de mis solicitudes anteriores con fechas, estados y respuestas recibidas, para tener un registro completo de todo lo que he gestionado. |
| HU-22 | Como empleado, quiero cancelar una solicitud que ya envié pero que aún no ha sido procesada, para corregir un error o retirarla si ya no la necesito. |
| HU-23 | Como usuario de Talento Humano, quiero reasignar una solicitud a otro responsable registrando un motivo obligatorio y dejando evidencia en el historial de la solicitud, para garantizar la trazabilidad del proceso. |
| HU-24 | Como gerente, quiero consultar un resumen de las solicitudes de Talento Humano por tipo y período — permisos, vacaciones, incapacidades y certificaciones — para tener visibilidad sobre el estado del equipo y tomar decisiones informadas. |
