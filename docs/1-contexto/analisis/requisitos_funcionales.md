# 9. Requisitos Funcionales

| ID | HU Relacionada | Descripción |
|----|---------------|-------------|
| RF-01 | HU-01 | El sistema debe permitir a los usuarios iniciar sesión mediante usuario y contraseña según el rol asignado. |
| RF-02 | HU-02 | El sistema debe permitir la recuperación de contraseña mediante correo electrónico registrado. |
| RF-03 | HU-03 | El sistema debe permitir registrar solicitudes de permisos laborales. |
| RF-04 | HU-04 | El sistema debe permitir registrar solicitudes de vacaciones indicando fechas y motivo. |
| RF-05 | HU-05 | El sistema debe permitir solicitar certificados laborales digitales. |
| RF-06 | HU-06 | El sistema debe permitir registrar incapacidades médicas adjuntando soporte clínico obligatorio. |
| RF-07 | HU-07 | El sistema debe permitir aprobar solicitudes según el rol autorizado. |
| RF-08 | HU-08 | El sistema debe permitir rechazar solicitudes indicando un motivo obligatorio. |
| RF-09 | HU-09 | El sistema debe asignar automáticamente un responsable inicial según el tipo de solicitud registrada. |
| RF-10 | HU-10 | El sistema debe enviar alertas automáticas al personal de Talento Humano cuando una solicitud permanezca más de 3 días sin movimiento. |
| RF-11 | HU-11 | El sistema debe validar automáticamente el saldo disponible de vacaciones antes de aprobar una solicitud. |
| RF-12 | HU-12 | El sistema debe generar automáticamente certificados laborales en formato digital una vez aprobados. |
| RF-13 | HU-13 | El sistema debe generar automáticamente un número de radicado único para cada solicitud registrada. |
| RF-14 | HU-13 | El sistema debe permitir buscar solicitudes mediante número de radicado único generado por la plataforma. |
| RF-15 | HU-14 | El sistema debe permitir adjuntar documentos de soporte en solicitudes de permisos e incapacidades. |
| RF-16 | HU-15 | El sistema debe permitir consultar el historial de cambios y acciones realizadas sobre las solicitudes. |
| RF-17 | HU-16 | El sistema debe permitir editar solicitudes mientras permanezcan en estado pendiente. |
| RF-18 | HU-17 | El sistema debe enviar notificaciones por correo electrónico cuando una solicitud cambie de estado. |
| RF-19 | HU-18 | El sistema debe permitir consultar reportes de tiempos de respuesta por tipo de solicitud y responsable. |
| RF-20 | HU-19 | El sistema debe permitir cambiar solicitudes al estado "En revisión" registrando obligatoriamente una nota explicativa. |
| RF-21 | HU-20, HU-21 | El sistema debe permitir consultar solicitudes e historial mediante filtros por estado, tipo, fecha y empleado, mostrando las fechas, estados y respuestas asociadas. |
| RF-23 | HU-22 | El sistema debe permitir cancelar solicitudes que aún no hayan sido aprobadas ni rechazadas. |
| RF-24 | HU-23 | El sistema debe permitir reasignar solicitudes entre responsables autorizados registrando el motivo y dejando evidencia en el historial. |
| RF-25 | HU-24 | El sistema debe generar reportes y estadísticas de solicitudes por tipo y período para consulta gerencial. |
| RF-26 | HU-15 | El sistema debe registrar automáticamente cada cambio de estado realizado sobre una solicitud. |
