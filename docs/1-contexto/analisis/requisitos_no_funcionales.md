#  Requisitos No Funcionales

| ID | Categoría | Descripción | Métrica |
|----|-----------|-------------|----------|
| RNF-01 | Rendimiento | El sistema debe cargar las solicitudes rápidamente. | Menos de 3 segundos por consulta. |
| RNF-02 | Disponibilidad | El sistema debe estar disponible para los usuarios durante el horario laboral. | Disponibilidad mínima del 99% mensual entre lunes y viernes de 7:00 a.m. a 6:00 p.m. |
| RNF-03 | Seguridad | El sistema debe requerir autenticación para acceder. | Acceso únicamente mediante usuario y contraseña. |
| RNF-04 | Seguridad | El sistema debe proteger la información de los empleados. | Datos cifrados en almacenamiento y transmisión. |
| RNF-05 | Usabilidad | El sistema debe ser fácil de utilizar para cualquier empleado. | Registro completo en menos de 2 minutos sin capacitación previa. |
| RNF-06 | Usabilidad | La interfaz debe adaptarse a dispositivos móviles y computadores. | Diseño responsive compatible con navegador web y móvil. |
| RNF-07 | Rendimiento | El sistema debe soportar múltiples usuarios conectados simultáneamente. | Hasta 30 usuarios concurrentes sin fallos críticos. |
| RNF-08 | Disponibilidad | El sistema debe realizar copias de seguridad automáticas. | Backup diario automático. |
| RNF-09 | Seguridad | El sistema debe registrar las acciones importantes realizadas. | Registro automático de auditoría por usuario y fecha. |
| RNF-10 | Portabilidad | El sistema debe funcionar en distintos navegadores modernos. | Compatibilidad con Chrome, Edge y Firefox. |
| RNF-11 | Mantenibilidad | El sistema debe permitir futuras mejoras sin afectar funciones existentes. | Las actualizaciones no deberán generar fallos críticos. |
| RNF-12 | Disponibilidad | El sistema debe permitir recuperación ante fallos. | Restauración de respaldo en menos de 2 horas. |
