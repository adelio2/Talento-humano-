# 99 - Archivos y Versiones Históricas

Esta carpeta almacena entregables, documentos y estructuras previas del proyecto para preservar la trazabilidad, autoría e historial sin eliminar trabajo anterior:

1. **`Proyecto_Nexa_Servicios_Documentacion_completa.docx`:**  
   Versión preliminar del documento maestro del proyecto que se encontraba en la raíz del repositorio. Fue sustituida formalmente como fuente de verdad por el documento definitivo aprobado fuera del repositorio (`Nexa servicios talento humano definitivo actual.docx`).

2. **`version-previa-1-contexto/`:**  
   Archivos originales de la fase de contexto y objetivos que se encontraban dispersos antes de la reorganización por fases numeradas del cronograma académico (Semanas 1 a 16).

> **Aviso:** Ningún archivo contenido en esta carpeta debe considerarse como versión vigente del proyecto. Consulte las carpetas `00-concepcion/`, `01-analisis/`, `02-diseno/` y `03-construccion/` para los artefactos activos.
